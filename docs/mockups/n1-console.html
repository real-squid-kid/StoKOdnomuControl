Н1 · решения для согласования

Макет без файлов, звука и USB. Обычные игровые команды здесь не выполняются.

  1. Группировка: команды и банк над ответами; справа заставка, Buzz!, экран и звук; отмена и остановка звука всегда внизу.
  2. Поддержка окон: предлагается сохранить BuildUi с отдельными функциями панелей и табличной раскладкой. Зрительские окна сохраняют Designer.
  3. Оформление: один профиль мероприятия; общее для основной игры, необязательные отличия раундов, отдельное для большой игры.
  4. Большая игра: заставка заменяет ответы; итог и таймер сохраняются, отсчёт не меняется.
  5. Звуки: предлагается оставить встроенными на Н2–Н6; пользовательские WAV — только если отдельно включишь этот пункт.

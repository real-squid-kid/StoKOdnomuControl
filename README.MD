# «Сто к одному» — табло и пульт оператора

Windows Forms, VB.NET, .NET Framework 4.8. Версия ветки `EchoKnowsBest` — 0.2. Подробная [памятка оператора](OPERATOR_GUIDE.MD), [исходный аудит](AUDIT.MD) и [статус его пунктов](AUDIT_PROGRESS.MD).

## Открытие в Visual Studio

Откройте `StoKOdnomuControl.sln` в Visual Studio 2022 с компонентом «Разработка классических приложений .NET» и .NET Framework 4.8 Developer Pack. Стартовый проект — **StoKOdnomuControl**. `RegressionTests` — консольные проверки, запускать его вместо приложения не нужно.

Восстановите пакеты NuGet через контекстное меню решения → «Восстановить пакеты NuGet». При установленном NuGet CLI можно выполнить `nuget restore StoKOdnomuControl.sln`. Затем выберите Debug/Release и соберите решение.

**Особенность этой ветки:** пульты `Form1` и `BigGameControl` используют программную компоновку в `BuildUi`, общие элементы — в `OperatorUi.vb`. Их прежние `.Designer.vb` удалены. Для изменения подписей/размещения редактируйте эти методы; не открывайте пульты в визуальном конструкторе с ожиданием старой раскладки. Обычный запуск и сборка `.sln` поддерживаются. Зрительские формы `Tablo`, `BigGameTablo`, а также «О программе» и пасхалка сохранили конструкторы.

## Сборка и проверки из PowerShell

Из корня проекта:

```powershell
./scripts/build.ps1
./scripts/verify.ps1
./scripts/verify.ps1 -Ui
./scripts/build.ps1 -Package
```

Скрипты находят MSBuild через `vswhere` установленной Visual Studio; интернет для сборки после восстановления пакетов не нужен. `-Ui` дополнительно проверяет команды кнопок и сохраняет снимки четырёх окон в отдельной временной папке. Звук в этом прогоне выключен; отчёт содержит путь к снимкам. Тесты используют свои сохранения, не затрагивая сохранённый матч оператора.

Автосохранение использует Windows `File.Replace`; запуск тестов в среде, запрещающей эту операцию, даёт ошибку записи. В обычном Windows-терминале такого ограничения песочницы нет.

`-Package` создаёт новый каталог `artifacts/release-<дата-время>/app` без старых DLL и результатов предыдущих сборок. Переносите **весь `app`**, включая DLL, `Fonts`, четыре TXT-базы и памятку. Запускайте `StoKOdnomuControl.exe`. Установка Windows Media Player больше не требуется.

## Устройство кода

| Файл | Назначение |
|---|---|
| `GameState.vb` | Типизированное состояние, правила начисления и переходов |
| `GameSession.vb` | Проверка команды до применения, общая история 100 отмен, сохранение и журнал |
| `QuestionBankReader.vb` | Проверка существующего формата TXT без изменения текущей базы при ошибке |
| `Form1.vb`, `BigGameControl.vb` | Действия оператора, черновики полей, обновление интерфейса |
| `Tablo.vb`, `BigGameTablo.vb` | Отображение снимка состояния без начислений и звуков |
| `BoardLayout.vb` | Масштабирование фона и подписей, комплектные шрифты, полноэкранный режим |
| `AudioService.vb` | Кэш декодированных WAV, независимые каналы эффектов/Buzz!/отсчёта |
| `Countdown.vb` | Отсчёт через Stopwatch и управление только его звуковым треком |
| `BuzzManager.vb` | Чтение выбранного HID-приёмника, допуск/блокировка и обработка ничьих |

`Option Strict On` действует для всего проекта. Вызовы `My.Computer.Audio`, WinMM-выбор первого джойстика и мёртвые COM-ссылки WMP удалены. NAudio оставлен в составе Core/WinMM и необходимых зависимостей, а не полного набора Asio/Midi/WinForms/Wasapi.

## Ресурсы и данные

В сборке осталось 23 глобальных ресурса: актуальный дизайн 2026 года, `bing`, пять `ff_reveal` и восстановленная пасхалка. 27 неиспользуемых записей удалены из `.resx`; исходные медиа сохранены в репозитории как материалы. В `Tablo.resx` больше нет шести копий картинок, заменявшихся при загрузке.

`Новый дизигн` — исходники и варианты оформления, `Новые звуки` — исторические звуки/фонограммы; пять `ff_reveal` оттуда ещё используются. Корневой XCF и PNG — художественные исходники. Для запуска не копируйте всю рабочую папку: используйте комплект `-Package`. Активные большие JPG в этой ветке сохранены без изменения изображения.

Шрифты JetBrains Mono Regular/Bold и их OFL-лицензия копируются в `Fonts`. Табло загружает их как частные GDI+ шрифты; ставить все 18 TTF в Windows не нужно. При отсутствии файлов используется системный моноширинный шрифт, поэтому для сохранения оформления переносите комплект целиком.

Игра и последние 100 отмен сохраняются в `%LOCALAPPDATA%/StoKOdnomuControl/game.xml`, предыдущий снимок — `game.xml.bak`, журнал — `actions.log`. Запущен может быть один экземпляр приложения. Для изолированных проверок каталог переопределяется переменной `STOKODNOMU_DATA_DIR`. В сохранение входят оба текущих табло, но не библиотека будущих раундов и не незавершённый отсчёт.

## Оборудование

Поддерживается приёмник с VID `054C`, PID `1000`. Кнопки читаются с того же HID-устройства, которым управляются лампы. Формат кнопок разбирается Windows HID parser по дескриптору; номера красных кнопок — 1, 6, 11, 16. Сопоставление соответствует [исходнику драйвера Sony в Linux](https://github.com/torvalds/linux/blob/master/drivers/hid/hid-sony.c), контракт парсера — [Microsoft HidP_GetUsages](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/hidpi/nf-hidpi-hidp_getusages).

Реальные USB-приёмник, лампы, аудиовыход и проектор должны пройти репетицию. Автоматические проверки проверяют правила арбитража, но не подтверждают работу конкретного приёмника или задержки его радиоканала.

# Статус аудита в EchoKnowsBest

Исходный `AUDIT.MD` сохранён как отчёт о прежнем состоянии. Здесь — связь его рекомендаций с изменениями ветки. Дата реализации: 25–26 октября 2026 года.

| Пункты | Результат |
|---|---|

| G04–G07 | Единый сброс, базовая цена и множитель, учёт уже начисленного ответа, отдельный режим заставок; история отмены |

| B01 | Следующий шаг выводится из раскрытий, ошибка не пропускает вопрос; новая игра и общая отмена |
| B02 | Доступны показ/исправление текста и очков любого вопроса обоих участников; разница цены корректирует итог |

| A03–A05 | Ресурсы декодируются один раз и закрываются при декодировании; проигрывания используют курсоры PCM; адресная остановка, каналы, обработка ошибок устройства |

| R06 | Оптимизация двух активных JPG отложена: изображения в этой ветке не перекодировались, оригинальный вид сохраняется |
| C01–C02 | Модель, команды и общий рендер; повторяющиеся обработчики заменены массивами и циклами; восстановление скрытого/переоткрытого табло без повторных эффектов |

## Границы изменений

- Пульты `Form1` и `BigGameControl` теперь редактируются в коде. Открытие/сборка решения поддерживаются; старого визуального редактирования раскладки этих двух пультов больше нет. Зрительские формы сохраняют Designer-файлы.
- Формат TXT и базовые правила сохранены, включая цель 150 по умолчанию и цены игры наоборот.
- Восстановление не включает незавершённый таймер, состояние USB и библиотеку будущих раундов. Неотправленные черновики не считаются опубликованными данными; для большой игры есть явное сохранение черновиков.
- Контракт HID сверялся с документацией Windows и сопоставлением красных кнопок. Проверка реального приёмника/ламп и радиоканала, слышимого звука и проектора остаётся частью репетиции.
- Проверяется обычный DPI при рендеринге и изменение размера холста. Полная матрица 100/125/150/200% DPI на физических мониторах в этой среде не прогонялась.

## Проверка для ревью

Автоматические сценарии находятся в `Tests/RegressionTests.vb`, запускаются `scripts/verify.ps1 -Ui`. Они проверяют загрузчик, начисления, скрытие/повторное открытие, правки, общий итог, сброс, отмену переноса и отдельных вопросов, восстановление истории, лимит 100 отмен, арбитраж Buzz!, команды кнопок и действительность шрифтов всех четырёх окон.

Ручной проход: загрузить одну из имеющихся баз → простая/двойная/тройная/наоборот → передать банк → отменить; затем большая игра → текст/очки → исправить цену конкретного вопроса → отменить → скрыть/вернуть первый столбец → новая большая игра → отменить. Отдельно проверить 20/25 секунд, звук Buzz! во время отсчёта, отключение USB и повторный допуск.
